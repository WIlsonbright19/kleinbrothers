# Klein Brothers Plumbing & Electrical

Responsive plumbing and electrical service website for San Francisco.

## Run locally

Requirements: Node.js 22 or newer.

```sh
npm install
npm run dev
```

## Build and deploy

```sh
npm run build
```

Deploy the generated `dist` directory to any static web host. The build uses relative asset paths, so it can be served from a domain root or a subdirectory. No server-side runtime or API keys are required.
